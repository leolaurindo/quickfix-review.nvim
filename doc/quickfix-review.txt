*quickfix-review.nvim*  Notes across native quickfix lists

=============================================================================

Review makes notes available from source buffers, quickfix/location-list rows,
and Git diff rows. Notes are stored on native items and mirrored into the
owned notes quickfix list.

Part of quickfix-kit.nvim:
https://github.com/leolaurindo/quickfix-kit.nvim

Dependencies:
- Required: quickfix-actions.nvim and quickfix-export.nvim
  https://github.com/leolaurindo/quickfix-actions.nvim
  https://github.com/leolaurindo/quickfix-export.nvim
- Optional dependency: quickfix-persist.nvim
  https://github.com/leolaurindo/quickfix-persist.nvim
- Optional integration: quickfix-diffs.nvim
  https://github.com/leolaurindo/quickfix-diffs.nvim

INSTALLATION                                                   *quickfix-review-installation*

lazy.nvim: >
  {
    "leolaurindo/quickfix-review.nvim",
    dependencies = {
      "leolaurindo/quickfix-actions.nvim",
      "leolaurindo/quickfix-export.nvim",
    },
    opts = { nerd_font = true },
  }
<

vim.pack (Neovim 0.12+): >
  vim.pack.add({
    "https://github.com/leolaurindo/quickfix-actions.nvim",
    "https://github.com/leolaurindo/quickfix-export.nvim",
    "https://github.com/leolaurindo/quickfix-review.nvim",
  }, { load = true })
  require("quickfix_review").setup()
<

Add Persist for automatic note-list persistence and Diffs for diff metadata.

SETUP                                                          *quickfix-review-setup*

  require("quickfix_review").setup({ send = "clipboard", nerd_font = true })

Regular export and send commands use template="plain" by default. Built-ins are
plain, check these notes, broader review, question, and implement. Configure a
different default with template="question"; custom templates are named entries
in templates and accept a prompt string or { prefix, suffix }. The
|QuickfixReviewExportFromTemplate| and
|QuickfixReviewSendAgentFromTemplate| commands choose a one-shot template.

Neovim cannot detect the terminal font. Set nerd_font=false to use the portable
pencil and AGENT fallbacks. Explicit glyph and quickfix.agent_label.text values
override these defaults. Both note and agent indicators use QuickfixReviewMark.

Notes are stored in item.user_data.quickfix_review. Producer fields and text
remain unchanged. The owned Quickfix Review list contains note text and
locations.

Automatic agent findings are watched for by default. To opt out: >
  require("quickfix_review").setup({
    agent = { response = { watch = false } },
  })
<
Ordinary Sidekick sends contain the formatted notes only; they do not require a
prompt, findings JSON, or mailbox write. Request the Quickfix Review skill when
you want findings returned as importable notes. Response generation and the
mailbox workflow are optional.
Agent notes use the robot glyph in source and native list rows; user notes use
the pencil. Without Nerd Fonts they fall back to AGENT and a portable pencil.
Range indicators and automatic source hover appear at both endpoints. Use
|QuickfixReviewHover| from any line inside a range. In a source window,
|QuickfixReviewHoverAll| toggles persistent per-note overlays at visible
endpoints. Scrolling updates them; leaving the window disables them.

|QuickfixReviewSearch| searches every entry in the current native quickfix or
location list by file path, producer text, and attached note text. With Snacks it
uses a compact live-search select picker. Confirming a result returns focus to
the list and places the cursor on that row without opening its source buffer.
|QuickfixReviewPick| and |QuickfixReviewPickCurrent| remain note-oriented source
navigation pickers.

NOTES                                                         *quickfix-review-notes*

Notes can be line-specific or file-level. Re-anchoring preserves the note ID,
text, creation time, metadata, and producer origin. Worktree notes use
whole-file fingerprints; Diffs notes use Git fingerprints. Changed sources
produce advisory stale warnings.

EXPORT                                                         *quickfix-review-export*

From a quickfix/location-list window, commands target the current list;
elsewhere they target the owned list for the active scope.

General export/send commands retain unannotated producer rows and omit agent
notes by default. Their ! variants include agent notes. ExportUser and
ExportAgent select only annotated notes of that origin. SendAgent always sends
only user notes; its ! means submit immediately.

ExportAndClear clears user notes only after successful export; its ! includes
and clears agent notes. SendAgentAndClear sends user notes, then clears all
notes in the selected target after success; its ! means submit immediately.
Failures never clear notes, and clearing annotations never deletes native rows.
Clearing a producer list also removes owned mirrors. Clearing the owned list
does not rewrite annotations still carried by another native producer list.

Built-in formats are markdown and json. Destinations are clipboard, file, and
optional sidekick. Included agent Markdown records have an [agent] label;
JSON and custom formats receive annotation metadata. Use
text(item, note, default_text) to choose note or producer text. See
|quickfix-export.nvim| for generic export contracts.
